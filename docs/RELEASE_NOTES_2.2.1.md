# INTERLOPER 2.2.1 — исправления 2.2.0

Мод: Minecraft **1.20.1**, Forge **47.2.20**, Java 17.
Файл: `interloper-1.20.1-2.2.1.jar`.

## Графити больше не отменяет вызовы Interloper'а

В 2.2.0 блок графити влиял на всё сразу: пока стена была чистой, исчезал **любой**
Interloper, а при активном графити он с шансом 45 % удалялся каждую секунду.
Из-за этого команда `spawn interloper` и `!interloper` в обычном мире выглядели
сломанными — Interloper появлялся и тут же пропадал, если игрок был рядом с улицей.

Теперь графити — это только шанс **случайного** спавна:

| Способ появления | Смотрит на графити |
|---|---|
| случайный спавн у улицы (раз в минуту) | да: нет графити → шанс 0 % |
| консоль `spawn interloper` / `ent_create interloper` | нет, появляется всегда |
| чат `!interloper` / `!hunt` | нет, появляется всегда |
| падение под бедрок (ветка 50/50) | нет, появляется всегда |
| демо-запись `play demo interloper_1` | нет, появляется всегда |
| случайный спавн в `source void` | не относится, графити живёт в верхнем мире |

## Из скайбокса можно выйти

В 2.2.0 `interloper:skybox` был ловушкой: войти можно, выйти нельзя. Добавлено три выхода:

1. **ПКМ по SKYBOX.exe внутри скайбокса** — сразу возвращает в обычный мир.
2. **Дырка в полу замка** — 3×3 блок «дырка в полу» внутри зала, обведённая
   блоками без текстуры. Наступил — ты в верхнем мире.
3. **Падение за карту** — если прокопаться сквозь пол скайбокса и упасть ниже
   `minBuildHeight`, игрока возвращает в обычный мир.

Во всех случаях при выходе сообщение `skybox.exe: disconnect`, точка респавна
возвращается в верхний мир, а сам SKYBOX.exe остаётся в инвентаре.

## Прочее

- Падение в скайбоксе больше не убивает: высота сбрасывается при выходе.
- Улица, рейвенчек, зонд, dm-редактор, SourceBox и Flashlight Nuke не менялись.
