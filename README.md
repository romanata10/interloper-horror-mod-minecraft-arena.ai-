# INTERLOPER: SOURCE VOID — хоррор-мод для Minecraft 1.20.1 (Forge)

Мод по мотивам ARG **INTERLOPER** от **Anomidae**. Консоль мёртвого движка, человек с
зонтом, который летит к тебе сквозь все блоки, измерение **source void** из одного
серого блока, ошибки VRAD и сломанные NPC.

> **Внимание:** мод содержит мерцающие изображения, громкие звуки и скримеры.
> Если у вас фотосенситивность — отключите мерцание в конфиге
> (`config/interloper-common.toml`, `visuals.flashing = false`).
>
> Фанатский проект, не связанный с Anomidae. Все тексты, звуки и текстуры
> сгенерированы процедурно специально для этого мода.

## Как это играется

1. Заходишь в мир — в инвентаре появляется **Console** (консоль в стиле Source engine).
2. ПКМ по консоли. В строке ввода уже набрано `play demo interloper_1`.
3. Нажимаешь **ENTER** — начинается **демо 1**: экран уходит в capture-режим, ползут
   строки движка, мигают текстуры, играет статика.
4. Демо заканчивается, ты снова в обычном мире, но консоль остаётся и в ней иногда
   сами собой появляются случайные команды из Source (`sv_cheats 1`, `noclip`, `map ...`).
5. Через несколько секунд слышны **колокольчики**. Сзади, сквозь все блоки, к тебе
   летит **Interloper** — чёрная фигура в стиле G-Man с зонтом.
6. Он касается тебя — и ты оказываешься в измерении **source void**.

## Измерение source void

* Пол из блока **Source Floor** — ровный серый цвет без деталей (`#7E7E7E`).
* В левом верхнем углу экрана подпись **`source void: minecraft`**, ниже
  `maps/source_void.bsp` и высота.
* Из того же блока генерируются структуры: **арки**, **геометрические фигуры**,
  **дома**, **скайблоки**, руины и висящие в воздухе «карты».
* Иногда в чат приходят случайные английские буквы и строки ошибок движка.
* Мобов мало: раз в некоторое время появляется **один** обитатель, бродит и
  исчезает, потом появляется следующий.

### Обитатели пустоты

| Сущность | Что делает |
|---|---|
| **Corrupted NPC** | Зомби в T-позе. Ходит без анимации, не поворачивается, проходит сквозь стены и блоки. Не нападает. |
| **VRAD** | Красная шахматная «ошибка отсутствующей текстуры». Видит сквозь блоки, летит за игроком. При касании в углах экрана мигают текстуры, бегут оранжевые строки ошибок — и ты умираешь. |
| **Crasher** | Житель с полностью сломанным ригом (кости под странными углами, анимации нет). Идёт за игроком сквозь всё. Касание — смерть. |
| **Cone** | Просто серый конус. Его можно убить, из него выпадает случайный предмет из Minecraft. |
| **dm_npc** | Эндермен с очень реалистичной походкой. На него нападают все агрессивные мобы. |
| **Skyghost** | Игрок в A-позе. Следит издалека, замирает, когда на него смотрят, пищит, спавнит случайных мобов (кроме дракона, визера и вардена), иногда убивает. |
| **Interloper (corrupt)** | Вытянутый вверх Interloper, у которого нижняя половина тела, правая рука и зонт — розово-чёрная шахматка «missing texture». В два раза быстрее. Касание — смерть и вылет с `error:crash_by-error`. |

Летающий Interloper в пустоте (и после первого посещения) тоже выкидывает из мира
с ошибкой **`error:crash_by-error`** — как и положено ARG.

## Предметы и блоки

| Предмет | Описание |
|---|---|
| **Console** | Консоль движка. ПКМ — открыть. ENTER — выполнить строку. |
| **Demo File** (5 типов) | Старые демо-записи: статика, кубмап, шёпот в чат. |

| **Anomaly Scanner** | Пингует скайбокс: тип ближайшей аномалии, расстояние, направление. |
| **The Umbrella** | Не открывать. (ПКМ — открыть.) |
| **Source Floor** | Тот самый серый блок. |
| **Engine Terminal** | Блок-терминал, принимает фрагменты скайбокса. |

## Команды консоли

```
play demo <1..5>     запустить демо
status               состояние движка
source_void          перейти в source void
spawn <entity>       corrupted_npc | vrad | crasher | cone | dmnpc | skyghost | interloper | interloper_corrupt
help                 список команд
disconnect           выйти из мира с ошибкой
```

Всё остальное отвечает `Unknown command`, как и положено движку, которого больше нет.

## Серверные команды

`/interloper help`, `/interloper hunt [игрок]`, `/interloper stop [игрок]`,
`/interloper reset`, `/interloper void`, `/interloper exit`, `/interloper console`,
`/interloper demo <1-5>`, `/interloper spawn <entity>`. Алиас `/interlope`.

## Мультиплеер

Мод рассчитан на сервер с несколькими игроками:

* каждая сущность привязана к **одному** игроку (UUID) и не переключается на того, кто ближе;
* смерть, выход или кик игрока завершает только его охоту — у остальных ничего не ломается;
* всё, что NPC делает с игроком (переход в source void, краш с `error:crash_by-error`),
  применяется только к этому игроку;
* консоль, демо-записи, экранные эффекты и структуры в пустоте — на каждого свои;
* в source void у каждого игрока своя точка появления;
* после вылета игроку даётся кулдаун (по умолчанию 3 минуты), в течение которого Interloper
  не крашит его повторно, а просто исчезает при касании;
* `/interloper stop <игрок>` (OP) — аварийно завершить все охоты против игрока.

## Измерения (2.2.0)

| Измерение | Что там |
|---|---|
| `source_void` | Серый пол, структуры из одного блока, **провал в пустоту до самого дна**, сундуки с книгой «the exit is white door and key», редкие Interloper. Skyghost'а здесь больше нет. |
| `xbox_360_dreams` | Дашборд Xbox 360 на весь экран, трава и панели с нормальными текстурами, **gm_construct**, **лабиринты Portal 1**, фрагменты Source-карт, сломанные персонажи, **дом из GMod**. |
| `white_door_bsp` | Белая комната с дверью и замком. Ключом открываешь дверь — и обратно в обычный мир. |
| `skybox` | Карманное измерение из **SKYBOX.exe**: замок на высокой горе, вода внизу. Здесь живёт **единственный** Skyghost. |

Путь к выходу: source void → провал → xbox 360 dreams → дом из GMod (сундук с ключом) →
дырка в полу → white_door_bsp → ключ + дверь → обычный мир.

Смерть в любом из этих измерений возвращает в то же измерение, консоль остаётся в инвентаре.

## Спавн и охота (2.1.0)

* В обычном мире **Interloper сам не появляется** — только консолью (`spawn interloper`)
  или командой в чате: `!interloper` / `!hunt`.
* Остальные мобы пустоты (corrupted npc, vrad, crasher, cone, dm_npc, skyghost, broken character)
  теперь **спавнятся и в верхнем мире**, но редко.
* В source void Interloper появляется сам, но редко, и гонит **не дольше одной минуты**;
  вернуться он может, только если снова увидит игрока.
* **Skyghost теперь спавнится только в `skybox`** — в верхнем мире и в пустоте его нет.
* Убей Skyghost → выпадет **зонт Interloper'а**, убивающий любую сущность с одного удара.
* Любая Source-команда в консоли отвечает: `you dont have admin comands on server FSKY`.


## Новое в 2.2.0

### Исправления
* **Провал в полу `source void` действительно ведёт под карту.** Раньше вырезалось только
  восемь слоёв, на дне оставался слой пола — теперь шахта идёт до `minBuildHeight`, и падение
  заканчивается в `xbox_360_dreams`.
* **Бедрок ломается** киркой.
* **Падение под бедрок не убивает.** На лету бросок 50/50: либо тебя вытягивает в
  `source void`, либо рядом уже летит Interloper и заканчивает падение сам.

### Улица и графити
* В мире появляется **одна улица**: дорога, четыре дома, фонари, стена с **графити**
  (человек с зонтом). Каждый день шанс перебрасывается (35–80 %): есть графити —
  Interloper может прийти, чистая стена — его не существует.
* Interloper рядом с активным графити с большим шансом просто исчезает.

### Новые предметы и блоки
| Предмет | Что делает |
|---|---|
| **Void Probe** | Запускается в `source void` из любого мира, летает как дрон и пишет, что нашёл. |
| **DM Editor** | ПКМ по `dm_npc` → NPC следует за игроком и защищает от монстров. |
| **RAVENCHECK.EXE** (блок) | Ставится у графити, каждый день пишет в чат шанс Interloper'а. |
| **Flashlight Nuke** | Из редкого сундука в `xbox_360_dreams`; убивает Interloper и Skyghost. |
| **SourceBox** | Дроп с битого Interloper'а: сканер аномалий + `cube` (куб, `Cube:error`, 5 зелий и 5 блоков за бросок в пустоту, перезарядка 10 минут). |
| **Skybox Shard / SKYBOX.exe** | Хлеб для Skyghost'а → осколки → SKYBOX.exe → карманное измерение `skybox`. |

* Выбрался из `source void` → достижение **`skybox_active`**, SKYBOX.exe остаётся в инвентаре
  навсегда (в том числе после смерти).
* На улице в сундуке лежит книга **«the skybox is jail for skybox just bread for skyghost»**.

## Исправления в 2.0.1

* NPC, убивший игрока, теперь **исчезает**, а не остаётся на месте смерти.
* Interloper удаляется перед вылетом с `error:crash_by-error`, а при входе игрока чистятся
  все охоты прошлой сессии — **бесконечный кик по кругу исправлен**.
* Добавлен кулдаун краша (`entities.crash_cooldown_seconds`).
* Полноценная поддержка мультиплеера (см. выше).

## Технические детали

* Minecraft **1.20.1**, Forge **47.x**, Java **17**, mappings `official`.
* Измерение: `data/interloper/dimension/source_void.json` + `dimension_type` + свой биом.
* Генерация: плоский слой `interloper:source_floor`, структуры строятся кодом
  (`VoidFabricator`) детерминированно по координатам чанка.
* Сеть: `ScreenEffectPacket` (эффекты экрана), `ConsoleLinePacket` (строки консоли),
  `ConsoleCommandPacket` (команды из GUI), `ChatGhostPacket` (сообщения «от никого»).
* Конфиг: `config/interloper-common.toml` — интенсивность эмбиента, частота охоты,
  отключение мерцания.

## Сборка

```bash
./gradlew build        # jar в build/libs/
./gradlew runClient    # тестовый клиент
```

CI (GitHub Actions) собирает jar, проверяет содержимое архива и запускает
дедикейтед-сервер на предмет ошибок загрузки.
