# INTERLOPER: SOURCE VOID 2.0.0

Релиз для **Minecraft 1.20.1 / Forge 47.x / Java 17**.
Файл: `interloper-1.20.1-2.0.0.jar` → `.minecraft/mods`.

## Что нового

### Консоль и демо
- Предмет **Console** появляется в инвентаре при первом входе в мир.
- GUI консоли в стиле Source engine: моноширинный лог, строка `]`, история команд,
  предзаполненная строка `play demo interloper_1`.
- **ENTER** запускает демо 1: capture-экран, мигание текстур, кубмап, статика,
  строки движка. После демо — «переподключение к minecraft».
- Консоль продолжает жить: движок сам дописывает случайные команды Source.

### Interloper
- Летает **сквозь все блоки и стены** прямо к игроку (noPhysics + собственный полёт).
- Перед появлением слышны **колокольчики** (`block.bell`).
- Касание в верхнем мире → перенос в **source void**; после первого переноса и в
  самом измерении → вылет с `error:crash_by-error`.
- Второй вариант: **Interloper (corrupt)** — вытянутый, быстрый, нижняя половина
  тела/рука/зонт из розово-чёрной шахматки; убивает и выкидывает из игры.

### Измерение source void
- Своё измерение (`interloper:source_void`): серый `Source Floor`, туман без неба.
- Надпись **`source void: minecraft`** в углу экрана.
- Процедурные структуры из одного блока: арки, геометрические фигуры, дома,
  скайблоки, руины, висящие «карты».
- Случайные английские буквы и ошибки движка в чате.
- Редкие одиночные спавны обитателей с последующим деспавном.

### Сущности
`Corrupted NPC` (T-поза, сквозь стены), `VRAD` (красная ошибка → оранжевые строки
и смерть), `Crasher` (сломанный житель, смерть при касании), `Cone` (дропает
случайный предмет), `dm_npc` (эндермен с живой походкой, его бьют все агрессивные
мобы), `Skyghost` (A-поза, слежка, писк, спавн мобов, редкое убийство),
`Interloper` и `Interloper (corrupt)`.
