# INTERLOPER: SOURCE VOID 2.1.0

Обновление для **Minecraft 1.20.1 / Forge 47.x / Java 17**.
Файл: `interloper-1.20.1-2.1.0.jar` → `.minecraft/mods`.

## Новые измерения

### source void
* Надпись `source void: minecraft` в углу, серый пол, структуры из одного блока, редкие мобы.
* **Новый фикс:** мобы пустоты теперь спавнятся и в обычном мире (раньше только в source void).
* **Провал в пустоту** — структура-дыра с воронкой из блоков без текстуры. Прыгаешь — падаешь
  в `xbox_360_dreams`.
* **Сундук без текстуры** — блоки `missing_texture` и книга **«the exit is white door and key»**.
* Interloper спавнится здесь сам, но редко. Skyghost — **только один одновременно**, после
  деспавна с шансом **40%** возвращается.

### xbox 360 dreams
* Всё оформлено как дашборд Xbox 360: зелёный градиент, HUD-панели «XBOX 360 DREAMS»,
  gamerscore, «achievement unlocked», полоски-«клинья» из панелей.
* Новые блоки: **Xbox Grass**, **Xbox Dirt**, **Dashboard Panel**, **Dashboard Glow**,
  **Portal Panel**, **Aperture Floor**, **Missing Texture Block** — с нормальными текстурами.
* Структуры: **gm_construct** (пандус, спавн-домик, столбы, физические пропы), **лабиринты
  Portal 1** из белых панелей, фрагменты других Source-карт (Dust-двор, офис, ящики),
  «клинья» дашборда, сундуки с припасами.
* **Сломанные персонажи** из Source-игр: стоят в неправильной позе, не двигаются, не смотрят,
  с полосой «отсутствующей текстуры» на модели (учёный, горожанин, солдат, робот).
* Мобы спавнятся, но реже, чем в source void.
* **Дом из Garry's Mod**: сундук с **белым ключом** и дырка в полу → `white_door_bsp`.

### white_door_bsp
* Одна белая комната: дверь, замок, свет.
* Открываешь дверь **белым ключом** → дверь открывается и тебя возвращает в обычный мир,
  дальше обычное выживание.

## Исправления

* **Смерть в source void** теперь возвращает в source void (точка респавна переезжает вместе с игроком);
  то же для `xbox_360_dreams` и `white_door_bsp`.
* **Консоль больше не пропадает** при смерти — возвращается после респавна.
* Обычный мир: **Interloper сам не спавнится**, только по консоли (`spawn interloper`) или
  командой в чате (`!interloper`, `!hunt`).
* В пустоте после смерти больше никто не караулит точку спавна: все охоты снимаются.

## Консоль

* Любая команда Source (`sv_cheats`, `noclip`, `map`, `impulse 101`, `connect`, `ent_fire`,
  `ai_disable`, `cl_*`, `r_*` …) теперь отвечает ровно одной строкой:
  **`you dont have admin comands on server FSKY`**, и ничего не делает.
* Работают только служебные: `play demo <1-5>`, `status`, `help`, `spawn <entity>`,
  `xbox`, `white_door`, `source_void`, `disconnect`.

## Новые предметы

| Предмет | Что делает |
|---|---|
| **Small White Key** | Открывает белую дверь и больше ничего. |
| **The Interloper's Umbrella** | Дроп с убитого Skyghost. Убивает любую сущность с одного удара. |
| **Missing Texture Block / Xbox блоки** | Строительные блоки новых измерений. |

## Проверка

CI: сборка jar, проверка содержимого архива (включая JSON измерений и новые текстуры) и
smoke-тест дедикейтед-сервера с самопроверкой: мод на старте пишет, что все три измерения
(`interloper:source_void`, `interloper:xbox_360_dreams`, `interloper:white_door_bsp`) реально
созданы. Сборка проходит только если это так.
