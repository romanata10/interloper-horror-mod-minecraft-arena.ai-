# INTERLOPER 1.0.0

Хоррор-мод по мотивам ARG **INTERLOPER** от Anomidae для **Minecraft 1.20.1 (Forge 47.x)**.

## Файл

`interloper-1.20.1-1.0.0.jar` → `.minecraft/mods`, требуется Forge 47.x для 1.20.1, Java 17.

## Что появляется в игре

**Сущности**
- **Interloper** («Человек с зонтом») — трёхметровая фигура, которая идёт за игроком,
  телепортируется за спину и **исчезает, если на неё смотреть**. Удар отправляет экран
  в capture-режим и наносит урон `interloper:interloped`. С него падает фрагмент скайбокса.
- **Skyghost** — висит на границе прогрузки, не двигается, пока вы смотрите, подходит,
  когда отворачиваетесь.

**Предметы и блок**
- **Demo File** ×5 типов — воспроизведение «записей демо»: помехи, кубмап, шёпот в чат,
  у Типа 5 — шанс призвать Интерлопера рядом.
- **Skybox Fragment**, **Anomaly Scanner**, **The Umbrella**, блок **Engine Terminal**.

**Атмосфера**
- Режиссёр случайных событий: шёпот за спиной, помехи, сердцебиение, тряска камеры,
  сообщения в чат «от никого», ночные охоты.
- Полноэкранные эффекты: глитчи, затемнение, кубмап-рендер, capture-оверлей, виньетка.

**Команда** `/interlope` (`/interloper`), алиасы: `help`, `hunt`, `skyghost`, `demo <1-5>`,
`effect <...>`, `terminal`, `fragment`.

## Важно

Мод содержит **мерцающие изображения и скримеры**. Отключить:
`config/interloper-common.toml` → `[visuals] flashing = false`.

## Сборка из исходников

```bash
./gradlew build      # build/libs/interloper-1.20.1-1.0.0.jar
```
