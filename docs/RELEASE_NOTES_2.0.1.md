# INTERLOPER: SOURCE VOID 2.0.1

Патч для **Minecraft 1.20.1 / Forge 47.x / Java 17**.
Файл: `interloper-1.20.1-2.0.1.jar` → `.minecraft/mods`.

## Исправлено

### NPC исчезает после убийства
- Убил игрока (Interloper, Interloper corrupt, VRAD, Crasher, Skyghost) — сущность **удаляется** сразу.
  Раньше она оставалась стоять на месте смерти и продолжала мешать.
- Дополнительная страховка: при смерти игрока удаляется и убийца, и все охотники,
  привязанные к этому игроку.

### Больше не выкидывает бесконечно
- Причина была в том, что Interloper после `error:crash_by-error` оставался в мире, привязанный
  ни к чему: после реконнекта он снова касался игрока и снова кикал — по кругу.
- Теперь: Interloper удаляется **до** кика, а при входе игрока все охоты с его прошлой сессии
  вычищаются (сразу и через секунду, когда чанки уже прогрузились).
- Добавлен кулдаун: после вылета игрок 3 минуты не подвергается крашу — Interloper в этот
  период просто исчезает при касании. Настраивается:
  `config/interloper-common.toml` → `entities.crash_cooldown_seconds` (по умолчанию 180).
- Interloper больше не живёт в мире дольше 3 минут: если не догнал — уходит сам.
- Выход с сервера (в том числе кик) тоже завершает охоту.

### Мультиплеер
- Каждая сущность привязана к **одному** игроку (UUID), а не к «ближайшему». Двое игроков —
  две независимые охоты, никто не крашится «за компанию».
- Привязка сохраняется в NBT: после перезагрузки чанков сущность помнит свою цель.
- Смерть, выход или кик игрока завершает только **его** охоту; сущности других игроков
  не трогаются.
- Демо-записи, консоль, экранные эффекты и переход в source void — полностью на одного игрока.
- Каждый входящий в source void получает свою точку спавна (раньше все появлялись в 0,0).
- Состояние (`source void` пройден, кулдаун) переносится через смерть и респавн и хранится
  отдельно у каждого игрока.

### Новые команды
- `/interloper hunt [игрок]` — запустить охоту на себя или на конкретного игрока (OP).
- `/interloper stop [игрок]` — завершить все охоты против себя/игрока (OP).
- `/interloper reset` — сбросить кулдаун краша.
